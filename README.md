# Personal Website

This is a lightweight static personal website built with HTML, CSS, and JavaScript.

## Project structure

- `index.html` — home page
- `about.html` — about page
- `projects.html` — projects page
- `blogs.html` — blog page
- `assets/css/` — stylesheets
- `assets/js/` — JavaScript files
- `assets/icons/` — local images and icons

## Run locally

Open `index.html` in a browser, or serve the project with a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
